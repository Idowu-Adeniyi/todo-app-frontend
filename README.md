# Todo App (React Frontend)

A minimal React-powered frontend application designed to demonstrate real-time input state handling.

## Key Features
* **Real-time Synchronization:** Utilizes an `onChange` event listener to instantly synchronize and update state values as you type.
* **Instant Text Mirroring:** Displays the typed string in real time elsewhere on the user interface before final submission.
* **State Management:** Uses React's standard state hooks to capture and stream text input dynamically.

## Tech Stack
* **Frontend:** React
* **Build Tool:** Vite

## Getting Started

1. Clone this repository to your local machine.
2. Run `npm install` to load dependencies.
3. Start the local server using `npm run dev`.
